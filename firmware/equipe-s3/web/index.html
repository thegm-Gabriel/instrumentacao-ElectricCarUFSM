O projeto

Carro Elétrico UFSM-CS

Instrumentação, telemetria e acompanhamento de um veículo elétrico experimental.

Um painel para aproximar a equipe dos dados do carro durante o desenvolvimento e os testes, e para compartilhar a experiência com visitantes.
