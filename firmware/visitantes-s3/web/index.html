Sobre o projeto

Carro Elétrico UFSM-CS

Construir, medir e compartilhar.

O veículo experimental aproxima o aprendizado da prática. A instrumentação permite acompanhar o que acontece durante os testes e transformar leituras em informações compreensíveis para a equipe e para o público.

O que acompanhamos

Movimento, percurso e, quando disponíveis, dados do sistema elétrico.

Como ler os dados
